# Дипломный проект
Сайт на PHP + MySQL с самописной админ-панелью

## Стек
- PHP 
- MySQL
- HTML+CSS+JS

## Как запустить:
1. Репозиторий склонировать в папку domains
2. Импортировать db_dump.sql
3. Настроить подключение через config.php
4. Открыть в браузере
5. Открыть admin/_.php для создания администратора
6. Для перехода в админ-панель http://uzgt-new/admin/admin.php
